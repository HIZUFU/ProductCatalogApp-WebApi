# Список производственных участков и перечень установленного на них оборудования

**Тема практической работы №1:** «Список производственных участков и перечень установленного на них оборудования».

Проект разработан на **ASP.NET Core MVC** с использованием **Entity Framework Core** и базы данных **SQLite**.

## Возможности приложения

- просмотр списка производственных площадок;
- добавление, просмотр, редактирование и удаление производственных площадок;
- просмотр списка оборудования;
- добавление, просмотр, редактирование и удаление оборудования;
- привязка каждой единицы оборудования к производственной площадке;
- выбор площадки из выпадающего списка при создании и редактировании оборудования;
- отображение названия связанной площадки вместо её числового идентификатора;
- просмотр оборудования, относящегося к выбранной площадке;
- фильтрация списка оборудования по производственной площадке.

## Модель данных

В приложении используются две основные сущности.

### Производственная площадка (ProductionSite)

Содержит:

- идентификатор;
- название;
- описание;
- список размещённого на площадке оборудования.

### Оборудование (Equipment)

Содержит:

- идентификатор;
- название;
- модель;
- инвентарный номер;
- идентификатор производственной площадки;
- ссылку на связанную производственную площадку.

Между сущностями установлена связь **один ко многим**: одна производственная площадка может содержать несколько единиц оборудования, а каждая единица оборудования относится к одной площадке.

## Реализованные операции

Контроллер оборудования поддерживает следующие операции:

| Операция | Реализация |
| --- | --- |
| Получение всех элементов | метод `Index` и вызов `ToListAsync()` |
| Выборка по условию | метод `Where()` по идентификатору площадки |
| Фильтрация | параметр `productionSiteId` в методе `Index` |
| Добавление | метод `Create` |
| Просмотр | метод `Details` |
| Редактирование | метод `Edit` |
| Удаление | методы `Delete` и `DeleteConfirmed` |

Для производственных площадок также реализованы основные CRUD-операции: создание, чтение, редактирование и удаление.

## Запуск проекта

### Через Visual Studio

1. Клонировать или скачать репозиторий.
2. Открыть файл решения в Visual Studio.
3. Дождаться восстановления NuGet-пакетов.
4. При необходимости применить миграции базы данных.
5. Запустить проект кнопкой **Start** или клавишей `F5`.

### Через командную строку

```bash
dotnet restore
dotnet ef database update
dotnet run
```

После запуска адрес приложения будет указан в терминале или в окне вывода Visual Studio.

Основные страницы:

- `/Equipments` — список оборудования и фильтрация по площадке;
- `/ProductionSites` — список производственных площадок.

## Работа с приложением

1. Создать производственную площадку в разделе **Производственные участки**.
2. Перейти в раздел **Оборудование**.
3. Создать оборудование и выбрать для него площадку из выпадающего списка.
4. При необходимости отфильтровать оборудование по выбранной площадке.
5. Для изменения или удаления записи использовать соответствующие действия рядом с элементом.

## Результат

Приложение реализует полный набор CRUD-операций, выбор всех элементов, выборку по условию и фильтрацию оборудования по производственной площадке. Данные сохраняются в базе SQLite через Entity Framework Core.
