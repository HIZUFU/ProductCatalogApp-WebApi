# Список производственных участков и оборудования (Web API)

Практическая работа №2 «Разработка приложения Web API». За основу взят проект из практической работы №1.

## Постановка задачи

Нужно создать решение ASP.NET Web API из двух проектов: серверной и клиентской части.
Тема: список производственных участков и перечень установленного на них оборудования.
В модели данных две связанные сущности (участок и оборудование, связь «один ко многим»).
В API два контроллера, в каждом есть выборка всех элементов, выборка по условию,
добавление, редактирование и удаление. API описано в Swagger, данные хранятся в SQLite.
Клиентская часть работает с данными через разработанное API.

## Что сделано

- проект `ProductCatalogApp.Api`: сущности, `DbContext`, миграция, DTO;
- контроллеры `ProductionSitesController` и `EquipmentsController`;
- фильтрация: участки ищутся по названию (`search`), оборудование фильтруется по участку (`productionSiteId`) и по тексту (`search`);
- подключён Swagger, при первом запуске база заполняется тестовыми данными;
- проект из первой работы переименован в `ProductCatalogApp.Client` и теперь берёт все данные из API.

## Запуск

Открыть `ProductCatalogApp.slnx` в Visual Studio, в свойствах решения выбрать
несколько запускаемых проектов (Api и Client) и запустить. Или запустить `run-all.bat`.

Swagger: http://localhost:5100/swagger, клиент: http://localhost:5034.
Адрес API для клиента указан в `ProductCatalogApp.Client/appsettings.json`.
